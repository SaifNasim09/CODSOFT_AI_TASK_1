# Chatbot With Rule-Based Responses

This project is a simple rule-based chatbot developed using Java as part of my Artificial Intelligence internship. It interacts with users by accepting text input, identifying keywords and predefined patterns, and generating appropriate responses using conditional statements.

## Features
- Interactive text-based conversation
- Predefined responses to greetings and common questions
- Keyword matching and basic text preprocessing
- Help menu and chatbot introduction
- Fallback responses for unrecognized inputs
- Simple and user-friendly console interface

## Technologies Used
- **Programming Language:** Java
- **Concepts:** Conditional Statements, Loops, String Handling, Pattern Matching, and Basic AI Concepts

## How It Works
The chatbot reads the user's message, processes the text, and checks it against predefined rules. If a matching rule is found, it displays the corresponding response. Otherwise, it provides a default response.

## Learning Outcomes
This project helped me improve my Java programming skills and understand how rule-based conversational systems work. It also introduced me to basic text processing and chatbot development.

**Note:** This chatbot uses predefined rules and does not use machine learning or a trained NLP model.
